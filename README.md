# Various Tools

A collection of practical tools and utilities for documents, automation, engineering, and everyday tasks.

## Tools

| Tool | Version | Description |
| --- | --- | --- |
| ReaderCapture | [v3.0.0](https://github.com/ThanosZr/various-tools/tree/reader-capture/v3.0.0/reader-capture) | Continuous document capture with persistent toolbar exclusion, a separate page splitter, PDF and full-resolution PNG export. |

## Organization

Each tool has its own directory, installation instructions, source code, tests and validation notes. Each version is stored on a branch named `<tool>/v<version>`.

The `main` branch contains the catalog. Open the corresponding version branch for the complete tool. See the validation notes and commit checks for test coverage and known limits.
