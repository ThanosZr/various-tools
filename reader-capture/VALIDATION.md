# Έλεγχοι ReaderCapture 0.3 — 21 Νοεμβρίου 2026

Τοπικά πέρασαν **43 δοκιμές Node** με το πραγματικό content.js, πάνελ, γεωμετρία, exporters και native canvas. Οι browser/Chrome APIs και η IndexedDB προσομοιώνονται σε αυτές τις δοκιμές.

Οι νέοι έλεγχοι καλύπτουν:

- Ανίχνευση και λήψη σελίδων διαφορετικού ύψους, με διαφορετικά κενά, χωρίς προφόρτωση όλου του εγγράφου.
- Απόλυτη ταύτιση των pixels κάθε σελίδας με το αρχικό δοκιμαστικό υλικό, μαζί με τις σειρές πίσω από μπάρες.
- Ανώνυμο absolute στοιχείο μέσα σε διαφανές fixed wrapper, χωρίς CSS όνομα ή toolbar role.
- Αρχική δοκιμαστική κύλιση για ανίχνευση στοιχείων που μένουν ακίνητα στην οθόνη μέσω script.
- Βήματα κύλισης που δεν ξεπερνούν τη ρύθμιση του χρήστη.
- Κεντράρισμα σελίδας που χωρά και μία μόνο λήψη της. Ακριβής ένωση υπολοίπου για μεγάλη σελίδα.
- Μετακίνηση μπάρας κατά το capture: απόρριψη προσωρινών τμημάτων και επανάληψη της ίδιας σελίδας.
- Διακοπή στη μέση της επόμενης σελίδας: παραμένουν μόνο οι προηγούμενες πλήρεις σελίδες.
- Εσωτερική κύλιση, χειροκίνητο πρότυπο και ασφαλής διακοπή σε αλλαγή zoom.
- Κλίμακες DPR 1, 1.25 και 2, μαζί με την τελική θέση κύλισης στο κάτω όριο. Δεν λείπουν ούτε επαναλαμβάνονται σειρές.
- Ενιαία δοκιμή πάνελ / αποθήκευσης / popup με αυτόματα όρια σελίδων.

Παραμένουν οι έλεγχοι της προηγούμενης έκδοσης: επιλογή με drag, κύλιση στο άκρο, βαθμονόμηση, zoom, PDF/ZIP, μετασχηματισμοί εικόνας, τρόπος 0.2 και μεγάλο PNG 35.050 σειρών.

## Πραγματικός browser

Το tests/browser.mjs εκτελεί πραγματικό Chromium μέσω GitHub Actions. Περιλαμβάνει σχεδίαση, edge scrolling, πραγματικό Chrome zoom, νέο τρόπο ανά σελίδα, έλεγχο μικρών βημάτων, δύο επίμονες μπάρες (ανώνυμο fixed wrapper και absolute στοιχείο που ακολουθεί την κύλιση μέσω script), ταύτιση pixels με καθαρό browser-rendered έγγραφο, popup και εξαγωγές PDF / PNG χωρίς κύλιση της αρχικής καρτέλας.

Η έκβαση του νέου browser run καταγράφεται στο αντίστοιχο commit / workflow. Η ύπαρξη του σεναρίου από μόνη της δεν αποτελεί επιτυχία ελέγχου.

## Όρια επαλήθευσης

Το συγκεκριμένο Scribd και ο Edge δεν έχουν επιβεβαιωθεί. Οι δοκιμές χρησιμοποιούν τοπικό, ελεγχόμενο υλικό και δεν τεκμηριώνουν συμβατότητα με κάθε viewer. Οι μεταβολές HTML, τα iframe, οι μη αναγνωρίσιμες σελίδες και το μόνιμα καλυμμένο περιεχόμενο παραμένουν περιορισμοί. Σελίδες διαφορετικού πλάτους χρειάζονται ξεχωριστές λήψεις.
