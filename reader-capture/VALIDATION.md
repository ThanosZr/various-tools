# Έλεγχοι ReaderCapture 3.0.0 — 21 Νοεμβρίου 2026

Τοπικά πέρασαν 33 δοκιμές Node, προσομοιωμένου DOM / Chrome APIs / IndexedDB και native canvas. Περιλαμβάνονται οι 29 έλεγχοι της προηγούμενης έκδοσης, προσαρμοσμένοι στη νέα έκδοση, καθώς και:

- Ενιαία καταγραφή με σταθερές μπάρες πάνω, στη μέση και κάτω στην οθόνη. Τα pixels της τελικής εικόνας ταυτίστηκαν πλήρως με το αρχικό δοκιμαστικό έγγραφο, χωρίς ελλείψεις, διπλές σειρές ή τις μπάρες.
- Η προφόρτωση ολοκληρώνεται πριν από το πρώτο screenshot. Η αρχική θέση κύλισης επανέρχεται.
- Ακύρωση με διατήρηση συνεχόμενης μερικής εικόνας.
- Χωρισμός, περικοπές και εξαγωγή περιοχής που διασχίζει πολλά τμήματα.
- Ενιαίο lossless PNG ύψους 35.050 pixels, χωρίς canvas πλήρους ύψους. Επαληθεύτηκαν οι διαστάσεις, όλα τα CRC και οι αποσυμπιεσμένες σειρές.
- Ενιαία δοκιμή πραγματικού panel.js / content.js / scan-store.js με αποθήκευση και άνοιγμα ξεχωριστού popup διαχωρισμού.

Το tests/browser.mjs είναι πραγματικό σενάριο Chromium / Playwright για σχεδίαση, edge scrolling, zoom, επίμονες μπάρες, popup διαχωρισμού, pixel comparison και εξαγωγές PDF/PNG χωρίς κύλιση της αρχικής καρτέλας. Το workflow ReaderCapture checks το εκτελεί στο GitHub Actions μαζί με τους ελέγχους Node.

Τοπικός πραγματικός Chromium δεν εκκινεί σε αυτό το περιβάλλον λόγω Unix socket περιορισμού. Η έκβαση του ελέγχου GitHub Actions πρέπει να ελέγχεται στο αντίστοιχο commit· η ύπαρξη του workflow δεν αποτελεί απόδειξη επιτυχίας.

Το headless harness προσθέτει host_permissions μόνο σε προσωρινό αντίγραφο δοκιμής, επειδή δεν έχει φυσικό toolbar gesture. Το παραγωγικό manifest χρησιμοποιεί activeTab, χωρίς καθολικό host_permissions και χωρίς debugger.

Το συγκεκριμένο έγγραφο Scribd και ο Edge δεν έχουν επιβεβαιωθεί σε πραγματική συνεδρία. Η δοκιμή μπαρών χρησιμοποιεί πρωτότυπο τοπικό δοκιμαστικό έγγραφο.
