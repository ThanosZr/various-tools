# ReaderCapture 0.2

Προηγούμενη αρίθμηση: 3.0.0. Η αλλαγή ονόματος διατηρεί τη λειτουργία αυτής της έκδοσης.

Ενιαία λήψη online εγγράφων και χωρισμός σε σελίδες μετά την καταγραφή. Λευκό περιβάλλον, Calibri και τοπική επεξεργασία.

## Η νέα ροή

1. Άνοιξε το έγγραφο και το ReaderCapture. Σχεδίασε το εύρος που θέλεις: κόκκινο πλαίσιο όσο σέρνεις, πράσινο μόλις αφήσεις. Στο άκρο η κύλιση συνεχίζεται μόνη της.
2. Διάλεξε **Ολόκληρη τη σχεδιασμένη περιοχή**, **Μέχρι το τέλος της κύλισης**, ή **Περιοχή σελίδας × πλήθος**. Για την τελευταία επιλογή όρισε την επόμενη αρχή στις προαιρετικές ρυθμίσεις και το πλήθος στο κεντρικό πλαίσιο λήψης.
3. Άφησε ενεργό τον **Αυτόματο αποκλεισμό σταθερών μπαρών**. Αν μια μπάρα δεν αναγνωρίζεται, πάτησε **Σημείωσε μπάρα** και επίλεξέ την πάνω στην ιστοσελίδα.
4. Πάτησε **Λήψη ενιαίας εικόνας**. Πρώτα γίνεται φόρτωση του εύρους με κύλιση, μετά η καταγραφή. Η κύλιση παραμένει απαραίτητη για screenshots και lazy loading, αλλά δεν χωρίζει πλέον το PDF την ώρα της λήψης.
5. Ανοίγει ξεχωριστό παράθυρο με όλη την αποθηκευμένη εικόνα. Κάνε κλικ για γραμμή κοπής, σύρε τη γραμμή για διόρθωση ή κάνε διπλό κλικ για αφαίρεση.
6. Ρύθμισε κοινό ύψος και διάκενο, προαιρετικές περικοπές ή εξαιρούμενες σελίδες. Οι γραμμές μπορούν να προταθούν και κοντά σε κενές περιοχές· έλεγξέ τις πριν την εξαγωγή.
7. Εξήγαγε **PDF**, **σελίδες PNG σε ZIP**, ή **ολόκληρη την εικόνα σε ένα PNG**. Η αρχική καρτέλα δεν κινείται σε αυτό το στάδιο. Μπορείς επίσης να προσθέσεις τις κομμένες σελίδες στην προηγούμενη συλλογή.

## Διόρθωση persistent bar

Οι ορατές σταθερές/κολλημένες μπάρες εξαιρούνται από τα διαθέσιμα τμήματα screenshot. Η επόμενη θέση κύλισης επιλέγεται ώστε οι γραμμές που βρίσκονταν πίσω από τη μπάρα να εμφανίζονται ακάλυπτες. Δεν σβήνει σειρές του εγγράφου, δεν ζωγραφίζει λευκό πάνω τους και δεν αλλάζει το DOM του ιστοτόπου για να κρύψει μπάρες.

Κάθε επόμενο τμήμα προσθέτει μόνο νέες, συνεχόμενες σειρές. Η καταγραφή διακόπτεται αν δεν μπορεί να εξασφαλιστεί συνέχεια. Αν κάποια γραμμή καλύπτεται μονίμως σε κάθε δυνατή θέση κύλισης, χρειάζεται αλλαγή των ορίων ή του viewer· το εργαλείο δεν ανακατασκευάζει περιεχόμενο που δεν εμφανίζεται.

## Μεγάλες εικόνες χωρίς απώλεια ανάλυσης

Η ενιαία εικόνα αποθηκεύεται εσωτερικά σε συνεχόμενα τμήματα PNG στην αρχική ανάλυση της προβολής. Στο παράθυρο εμφανίζεται ως μία μεγάλη εικόνα. Έτσι δεν περιορίζεται όλο το έγγραφο από το μέγιστο ύψος ενός canvas και δεν μικραίνει υποχρεωτικά η ανάλυσή του.

Η εξαγωγή ολόκληρου PNG γράφει διαδοχικά τις σειρές με συμπίεση DEFLATE, χωρίς canvas πλήρους ύψους. Πολύ μεγάλες εικόνες εξακολουθούν να χρειάζονται διαθέσιμη μνήμη και μπορεί να ξεπερνούν τα όρια άλλων εφαρμογών προβολής. Για PDF, κάθε κομμένη σελίδα επεξεργάζεται χωριστά, με όριο περίπου 40 MP / 30.000 pixels ανά διάσταση.

## Εγκατάσταση / αναβάθμιση

[Λήψη ZIP από το GitHub](https://github.com/ThanosZr/various-tools/archive/refs/heads/reader-capture/v0.2.zip). Αποσυμπίεσε το αρχείο και επίλεξε τον υποφάκελο **reader-capture/extension**.

Στο chrome://extensions ή edge://extensions ενεργοποίησε Developer mode και φόρτωσε τον φάκελο **extension** με Load unpacked. Για αναβάθμιση αντικατάστησε τα περιεχόμενα του ίδιου φακέλου extension, πάτησε Reload στην επέκταση, κλείσε το παλιό πάνελ και **ανανέωσε επίσης το έγγραφο**.

Η παλιά συλλογή και τα αντίγραφα .rcap παραμένουν συμβατά. Οι ενιαίες λήψεις αποθηκεύονται ξεχωριστά στον browser και ανοίγουν ξανά από το **Άνοιγμα διαχωρισμού**. Η διακοπή διατηρεί τα ολοκληρωμένα τμήματα ως μερική λήψη. Πριν απεγκατάσταση, εξήγαγε ό,τι θέλεις να διατηρήσεις.

Δεν χρειάζεται Node/Python για χρήση. Για τοπικά demo ενεργοποίησε Allow access to file URLs. Το demo/viewer.html έχει σταθερή κεφαλίδα 64 px. Το demo/nested.html έχει εσωτερική κύλιση.

## Χωρισμός και ποιότητα

Η προεπισκόπηση διατηρεί τα αρχικά pixels. Η ρύθμιση zoom του παραθύρου επηρεάζει μόνο την προβολή. Ύψος/διάκενο κοπής και γραμμές μετρώνται στα pixels της αποθηκευμένης εικόνας. Το γκρι και η μείωση πλάτους εφαρμόζονται στην εξαγωγή PDF/σελίδων, χωρίς αλλαγή της αρχικής λήψης. Το ολόκληρο PNG παραμένει αρχικό και χωρίς απώλειες.

Το PDF περιέχει εικόνες χωρίς OCR. Δεν αποκτά επιλέξιμο κείμενο. Οι παλιοί τρόποι λήψης βρίσκονται στις προαιρετικές ρυθμίσεις.

## Πρόσβαση και περιορισμοί

Καταγράφει μόνο ό,τι μπορεί να εμφανίσει ο browser. Δεν ξεκλειδώνει μη διαθέσιμες σελίδες, δεν παρακάμπτει σύνδεση/συνδρομή ή προστασίες και δεν αφαιρεί καλύμματα πρόσβασης. Η ανάλυση εξαρτάται από τη διαθέσιμη προβολή. Δεν φορτώνει εξωτερικό κώδικα, δεν στέλνει screenshots σε server και δεν χρησιμοποιεί analytics.

Η επιλογή ακολουθεί τη γεωμετρία της σελίδας στο zoom πριν τη λήψη. Στην ενιαία καταγραφή κράτησε σταθερό zoom και παράθυρο· αλλαγή τους διακόπτει τη λήψη για να μη συνδυαστούν διαφορετικές αναλύσεις. Οι πολύ ιδιαίτεροι viewers ή iframe μπορεί να χρειάζονται χειροκίνητες ρυθμίσεις. Η προφόρτωση έχει όριο 2000 θέσεις και η καταγραφή 10000 τμήματα.

## Για ανάπτυξη

Η επέκταση δεν απαιτεί build και δεν φορτώνει εξωτερικό κώδικα. Χρησιμοποιεί activeTab, χωρίς μόνιμη πρόσβαση σε όλους τους ιστοτόπους. Chrome 116+· η συμβατότητα Edge δεν επιβεβαιώθηκε εδώ.

- `npm test`: έλεγχοι Node για πυρήνα, βαθμονόμηση και batch, χωρίς επιπλέον πακέτα.
- `npm install` και `npm run test:all`: όλοι οι έλεγχοι, μαζί με native canvas και ολοκληρωμένη δοκιμή προσομοιωμένου πάνελ.
- `npm run test:browser`: έτοιμο σενάριο πραγματικού Chromium / Playwright, με εγκατεστημένο Chromium και κατάλληλο CHROMIUM_PATH αν χρειάζεται.
